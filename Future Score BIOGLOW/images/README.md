現在は**公式 PDF から切り出した画像を配置済み**です（差し替えたい場合は下の仕様に合わせて上書きしてください）。

## 出典と作り直し方

`drafts/y-uno/FLL-Challenge Future/公式資料/The Game ルール関連/BIOGLOW_ミッションルール_英語.pdf`
の各ミッションページに埋め込まれたモデル写真（透過 PNG）を取り出し、
ラベル文字を含めずに白背景の正方形（500×500px）へ合成したもの。
ページ全体をラスタで切り取ると英語ラベルが写り込むため、埋め込み画像を個別に取り出して合成している。

## 推奨仕様

- **正方形**（1:1）。表示は 54px（スマホ）／66px（iPad 縦）なので、**400×400px 程度**あれば十分です。
- 形式は **JPEG**（`.jpg`）。1 枚 100KB 以下を目安に。
- 画像が無い間は「MISSION 01」のような**番号だけの枠**が表示されます。1 枚ずつ追加していけば、置いたものから順に反映されます。
- ファイル名を変えると表示されません。**上の表の名前のまま**置いてください。

## 撮り方のヒント

- ミッションモデルを**フィールド上の設置位置で真上または斜め上から**撮ると、レフェリーが現物と見比べやすくなります。
- **得点条件が判定される部分**（例：01 なら若い森・グランドツリー・洞の木の 3 か所、02 なら林冠のチャンバー）が写るように寄せて撮ってください。
