# ミッション写真の置き場

`index.html` のカード左上に出る**正方形サムネイル**の画像。
現在は**公式ルールブックから切り出した画像を配置済み**です（差し替えたい場合は下の仕様に合わせて上書きしてください）。

## 出典と作り直し方

公式 **Robot Game Rulebook（英語原本）P9〜P12** のミッションカードに埋め込まれたモデル写真を
1 枚ずつ取り出し、白背景の正方形（500×500px）に収めたもの。

- 原本 URL: <https://firstinspires.blob.core.windows.net/fll/challenge/2026-27/fll-challenge-bioglow-rgr.pdf>
  （リポジトリには 10MB 超のためコミットしていない。`../../公式資料/README.md` を参照）
- ページ全体をラスタで切り取ると英語ラベル（"Drone" "LiDAR Map" 等）と赤い引き出し線、
  カードの薄緑背景が写り込むため、**埋め込み画像だけを個別に取り出している**
- リポジトリ内の `../../公式資料/images/rgr-09.jpg`〜`rgr-12.jpg` は同じページの
  スクリーンショット。原本 PDF が手元に無いときはこちらから切り出してもよい（ラベルは写り込む）

**08「からみつき」と 09「調査プラットフォーム」は原本でも同じ大木モデルの写真**のため、
サムネイルもよく似た絵柄になります（誤りではありません）。

## 推奨仕様

- **正方形**（1:1）。表示は 54px（スマホ）／66px（iPad 縦）なので、**400×400px 程度**あれば十分です（現在の配置済み画像は 500×500px・各 19〜51KB）。
- 形式は **JPEG**（`.jpg`）。1 枚 100KB 以下を目安に。
- 画像が無い間は「MISSION 01」のような**番号だけの枠**が表示されます。1 枚ずつ追加していけば、置いたものから順に反映されます。
- ファイル名を変えると表示されません。**上の表の名前のまま**置いてください。

## 撮り方のヒント

- ミッションモデルを**マット上の設置位置で真上または斜め上から**撮ると、レフェリーが現物と見比べやすくなります。
- **得点条件が判定される部分**（例：01 なら裏返した LiDAR マップ、12 なら杖と支持タイ）が写るように寄せて撮ってください。
